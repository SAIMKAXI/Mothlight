# Android preview signing

Mothlight preview APKs use one persistent **private test-only** signing key. Every subsequent preview APK must be signed with this exact keystore to install as an update over the previous preview.

## Required GitHub Actions secrets

Add these two repository secrets under **Settings → Secrets and variables → Actions**:

| Secret | Value |
|---|---|
| `MOTHLIGHT_TEST_KEYSTORE_BASE64` | Entire contents of the supplied `MOTHLIGHT_TEST_KEYSTORE_BASE64.txt` file |
| `MOTHLIGHT_TEST_KEYSTORE_PASSWORD` | Contents of the supplied password file |

The key alias is fixed in the workflow as `mothlight-test`; the key password is the same as the keystore password. Never commit the keystore, Base64 text, or password to the repository. Keep a secure offline backup of the keystore and password. If this key is lost, Android will reject future updates signed with a replacement key.

The Android workflow fails early with a clear message if either secret is missing. It restores the keystore on the runner and explicitly configures the Release build variant to use it.

## One-time transition from v0.2.8

v0.2.8 was signed with a temporary debug key generated by its CI runner. That signing key is not persistent, so Android can reject v0.2.9 as an in-place update with a signature/certificate mismatch.

Before installing v0.2.9, export/share any notes you need, then uninstall the older Mothlight preview and install v0.2.9 fresh. **Uninstalling clears the app's local data.** Once v0.2.9 is installed, future preview APKs signed with this same keystore can update normally without uninstalling.

This key is for tester sideloads only. Do not use it for Google Play or production distribution.
