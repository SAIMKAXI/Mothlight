# Android preview signing

Mothlight preview APKs are signed automatically with the standard Android debug certificate generated by the GitHub Actions runner. **No custom keystore or GitHub Actions signing secrets are required.**

These APKs are for direct tester sideloading only, not Google Play production. Since each CI run may generate a different debug certificate, Android may reject an in-place update from a previous preview. If that happens, back up important notes using the app's Share note action before uninstalling the old preview. Uninstalling clears the app's local data.

The signing certificate does not affect a fresh installation. If a newly downloaded APK fails to install on a clean device, capture the exact Android installer error so the APK compatibility or packaging issue can be diagnosed separately.
